# Demo fixtures

Installed by `bin/magento italgres:demo:install` into `pub/media/italgres/configurator/`.

| Folder | Content | Source / licence |
|---|---|---|
| `models/GlamVelvetSofa.glb` | Sofa | © 2021 Wayfair LLC, CC BY 4.0 (Khronos glTF Sample Assets). Attribution is shown under the viewer. |
| `models/SheenChair.glb` | Lounge chair | © 2021 Wayfair LLC, CC BY 4.0 (Khronos glTF Sample Assets). |
| `models/FioraTable.glb` | Coffee table | Generated by `tools/make_table.py` for this demo. |
| `models/ModularSofa.glb` | Lucca sectional: hidden element templates (`Element_Arm`, `_Chaise`, `_Ottoman`, `_Seat`, `_Seat15`) | Generated by `tools/make_modular_sofa.py`, shaped after the iONE360 "Dream" demo (two-tier piped back, flared arm with armrest, black feet). |
| `textures/*_albedo/normal/rough.jpg` (fabrics, leather, woods) | PBR maps | Poly Haven, CC0. Fabric/leather albedo maps were desaturated so option colours can tint them. |
| `textures/<slab>_albedo.jpg` (Calacatta, Statuario, ...) | Porcelain slab looks | Procedural, generated by `tools/marble.mjs`. |
| `swatches/*.jpg` | Option tile images | Crops of the textures above. |

These are stand-ins: the real catalogue needs the client's own 3D models (separate parts per
configurable area, real-world scale in metres, UV-mapped) and their actual material scans.
