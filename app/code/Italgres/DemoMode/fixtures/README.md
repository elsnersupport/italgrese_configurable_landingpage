# Demo fixtures

Installed by `bin/magento italgres:demo:install` into `pub/media/italgres/configurator/`.

| Folder | Content | Source / licence |
|---|---|---|
| `models/GlamVelvetSofa.glb` | Sofa | © 2021 Wayfair LLC, CC BY 4.0 (Khronos glTF Sample Assets). Attribution is shown under the viewer. Changed: textures re-encoded as WebP, geometry Draco-compressed. |
| `models/SheenChair.glb` | Lounge chair | © 2021 Wayfair LLC, CC BY 4.0 (Khronos glTF Sample Assets). Changed: textures re-encoded as WebP, geometry Draco-compressed. |
| `models/FioraTable.glb` | Coffee table | Generated by `tools/make_table.py` for this demo. |
| `models/ModularSofa.glb` | Lucca sectional: hidden element templates (`Element_Arm`, `_Chaise`, `_Ottoman`, `_Seat`, `_Seat15`) | Generated by `tools/make_modular_sofa.py`, shaped after the iONE360 "Dream" demo (two-tier piped back, flared arm with armrest, black feet). |
| `textures/*_albedo/normal/rough.webp` (fabrics, leather, woods) | PBR maps | Poly Haven, CC0. Fabric/leather albedo maps were desaturated so option colours can tint them. |
| `textures/<slab>_albedo.webp` (Calacatta, Statuario, ...) | Porcelain slab looks | Procedural, generated by `tools/marble.mjs`. |
| `swatches/*.webp` | Option tile images | Crops of the textures above. |
| `images/*.jpg` | Product images (share previews, structured data, admin grid) | Renders of each default configuration made with the configurator's own snapshot (1200 px). Added only while a product has no image. |

All models are shipped compressed (WebP textures + Draco geometry, see
`Configurator/frontend-src/README.md`); the generators in `tools/` write uncompressed files, so compress
their output before replacing a fixture. Textures are WebP (quality 70–82, normal maps 80–90).

These are stand-ins: the real catalogue needs the client's own 3D models (separate parts per
configurable area, real-world scale in metres, UV-mapped) and their actual material scans.
